task 4 -- Step 5 default-arm byte-identity proof

Ruling R4: the control is the BRANCH HEAD BEFORE THIS TASK (263538df, task 3's
commit), reached with `git stash`, not master.  `git stash` cannot revert
committed work, so a stash-based comparison can only ever answer "did MY
uncommitted change move the default arm".  The against-master control is the
later 72-cell corpus gate.

method: the DSP blueprint string is `BLUEPRINT:<header fields>,"<base64
        payload>"<MD5>`.  Header field 8 is a wall-clock .NET tick stamped at
        emit time (codec.py:376) and the trailing MD5 covers it, so two runs of
        the SAME tree differ in exactly those bytes.  What is compared is the
        base64 LAYOUT PAYLOAD -- the entire placement -- plus the header with
        field 8 masked.

command: uv run flab2bp "$URL" --strategy freeform --budget 30
